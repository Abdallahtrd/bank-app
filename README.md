# Bank App 🏦

A banking application built with Python as a project to practise object-oriented programming and software development.

## Features

* Deposits and withdrawals
* Transaction history
* Account-number generation
* Account management *(in development)*

## Technologies

* Python
* Git and GitHub

## Status

Currently under development.

## Disclaimer

This is an educational project and is not intended for real financial transactions.
